Meme Stock Sentiment Predictor

**An AI-powered web application that analyzes retail investor sentiment to anticipate meme stock movements.**

🔗 **[Live Demo](https://meme-stock-predictor--power28.replit.app/)**

 What It Does
<img width="1470" height="956" alt="Recording 2026-06-11 at 21 03 55" src="https://github.com/user-attachments/assets/fa8b32ca-08e5-4bed-8c36-d75c3787eba8" />


This application scrapes real-time posts and comments from the r/wallstreetbets community on Reddit to gauge market momentum. By employing a dual NLP pipeline, it leverages **VADER** to decode internet slang and emojis alongside **FinVADER** to accurately weigh domain-specific financial context. The system aggregates these sentiment metrics to flag potential high-conviction retail market rallies.

 Tech Stack

* **NLP Engines:** VADER, FinVADER
* **Data Ingestion:** PRAW (Reddit API)
* **Backend & Analytics:** Python, Pandas
* **Deployment:** Replit
